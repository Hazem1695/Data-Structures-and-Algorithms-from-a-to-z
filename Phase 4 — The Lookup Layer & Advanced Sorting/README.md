# Phase 4: The Lookup Layer & Advanced Sorting
Shifting focus from scanning elements to instant retrieval and optimal dataset partitioning.
* **Milestone 4.1: Divide and Conquer Sorting**
  * Merge Sort: Recursive array splitting, sub-array sorting, and linear merging.
  * Quick Sort: Pivot selection strategies and in-place memory partitioning algorithms.
* **Milestone 4.2: Hashing Mechanisms**
  * Designing deterministic Hash Functions to map data to indices.
  * Collision Resolution strategies: Chaining (Linked Lists) vs. Open Addressing (Linear Probing).
* **Milestone 4.3: Hash Tables & Sets**
  * Hash Maps: $O(1)$ average-time key-value storage and retrieval workflows.
  * Hash Sets: Unique item collections used for instant historical duplicate checking.
