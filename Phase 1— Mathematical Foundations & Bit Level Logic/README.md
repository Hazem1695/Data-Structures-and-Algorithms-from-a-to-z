# Phase 1: Mathematical Foundations & Bit-Level Logic
Before writing algorithms, you must learn the mathematical laws that govern computer performance and memory.
* **Milestone 1.1: Big O Notation & Complexity Analysis**
  * Time and Space complexities ($O(1)$, $O(\log N)$, $O(N)$, $O(N \log N)$, $O(N^2))$.
  * Analyzing loops, nested loops, and consecutive blocks of code.
  * Simplifying equations (Dropping constants and keeping dominant terms).
* **Milestone 1.2: Bitwise Operations**
  * The binary number system and raw bit representation.
  * Bitwise operators: AND (`&`), OR (`|`), XOR (`^`), NOT (`~`).
  * Bit-shifting operations (`<<`, `>>`) for high-performance flag tracking.
* **Milestone 1.3: Fundamental Counting & Combinatorics**
  * Permutations and combinations.
  * Calculating state-space sizes to understand problem scales.
