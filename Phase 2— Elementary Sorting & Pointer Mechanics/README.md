# Phase 2: Elementary Sorting & Pointer Mechanics
Learning how a computer handles linear blocks of memory and how to navigate indices efficiently.
* **Milestone 2.1: Contiguous Memory Layouts**
  * How arrays are stored physically in RAM.
  * The cost of reading, inserting, and deleting from fixed memory blocks.
* **Milestone 2.2: Brute-Force & Iterative Sorting**
  * Bubble Sort: Nested loops, adjacent comparisons, and manual value swapping.
  * Selection Sort: Tracking the minimum element and placing it at the frontier.
  * Insertion Sort: Building a sorted partition by shifting items backward.
* **Milestone 2.3: Two-Pointer Techniques**
  * Converging pointers (Left and Right pointers moving toward the center).
  * Fast and Slow pointers (Tortoise and Hare technique for cycle detection).
* **Milestone 2.4: Sliding Window Framework**
  * Fixed-size windows for running calculations.
  * Dynamic-size windows for tracking varying sub-segments.
