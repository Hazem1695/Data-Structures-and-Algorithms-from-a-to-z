# Phase 3: Linear Data Structures (Built From Scratch)
Moving away from built-in language structures to build your own fundamental containers using pointers.
* **Milestone 3.1: Static vs. Dynamic Arrays**
  * Creating custom arrays and managing size expansion mechanisms manually.
* **Milestone 3.2: Linked Lists**
  * Singly Linked Lists: Node creation, pointer links, head/tail management, and manual deletion.
  * Doubly Linked Lists: Managing simultaneous forward and backward pointers.
* **Milestone 3.3: Stacks (LIFO - Last In, First Out)**
  * Implementing push, pop, and peek behaviors using arrays and linked nodes.
* **Milestone 3.4: Queues (FIFO - First In, First Out)**
  * Implementing enqueue and dequeue operations without creating memory bottlenecks.
